This system defines the channels message format, `dyad-channels/1` (the channels craft's `templates/message.md`):
few required fields, any unknown field kept, and a version in every record. A record in it conforms when it carries
the six required fields and a listed kind. The protocol text received is used under this repository's licence, the
one a member installs under. `channels` is the canonical craft name, held by this system. A system whose craft is
also named `channels` may rename it or adopt this one. Channel policy, the read schedule included, is set per
channel in its registry entry.
